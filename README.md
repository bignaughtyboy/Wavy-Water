## Features

* 🌊 Animated water waves in Vanilla Minecraft
* ⚡ No shader pack required
* 📦 Lightweight and easy to install
* 🎮 Designed to stay close to the vanilla aesthetic
* 🆕 Updated for **Minecraft 26.2**

The wave effect is intentionally simple and stylized, adding movement and depth to oceans, rivers, lakes, and other water surfaces without dramatically changing Minecraft’s original look.

---

## Installation

1. Download the resource pack.
2. Open **Minecraft > Options > Resource Packs**.
3. Drag the pack into the resource pack folder.
4. Enable the pack and enjoy animated water.

## Notes

This is a **resource pack**, not a mod or shader pack.

Some rendering mods that replace Minecraft’s rendering pipeline (such as certain Sodium-based configurations) may prevent the wave effect from working correctly.
